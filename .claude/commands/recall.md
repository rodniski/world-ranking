Buscar contexto relevante no wiki do projeto antes de agir.

Pergunta ou topico: $ARGUMENTS

Siga o protocolo de query:

1. **Leia o index**: comece por `obsidian/wiki/index.md` para identificar paginas relevantes

2. **Leia as paginas**: abra e leia as paginas identificadas como relevantes

3. **Sintetize**: responda a pergunta/topico com base no que encontrou, citando as paginas wiki com [[links]]

4. **Avalie**: se a resposta envolver informacao com `confidence: low`, sinalize explicitamente

5. **Opcional — nova pagina**: se a analise gerou insight valioso que nao existe no wiki, pergunte ao usuario se quer salvar como comparison ou synthesis

6. **Atualize o log**: registre a query em `obsidian/wiki/log.md`

Exemplos de uso:

- `/recall qual a metodologia de normalizacao?`
- `/recall por que dois niveis de gate de MACRO?`
- `/recall como funciona o collector base?`
- `/recall historico de decisoes sobre pesos default`
- `/recall fontes priorizadas Alta`
